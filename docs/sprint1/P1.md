## P1-01 — Titres de chapitres dans les PDF

- **Fichier** : `backend/app/services/importer.py`
- **Test** : `test_importer.py::test_pdf_titres_detectes` + `test_pdf_sans_titre_une_page_par_chapitre`
- **But** : CA1.3 complet — un PDF de cours n'a pas de `#`, on repère donc ses titres
  avec des **motifs simples**.

```python
MOTIF_TITRE_PDF = re.compile(r"^\s*(chapitre\s+\d+\b.*|\d{1,2}\.\s+\S.*)$", re.IGNORECASE)

def est_titre_pdf(ligne: str) -> bool:
    """Vrai si la ligne ressemble à « Chapitre 3 … » ou « 2. Titre »."""

def decouper_texte_par_titres(lignes: list[str], titre_par_defaut: str) -> list[ChapitreImporte]:
    """Découpe des lignes en chapitres à partir des lignes-titres repérées."""
```

Règles :
- Lire **toutes** les pages, concaténer leurs lignes (`extract_text().splitlines()`).
- Une ligne-titre doit faire **au plus 80 caractères** (au-delà, c'est une phrase
  qui commence par un numéro, pas un titre).
- `1.5 Introduction` n'est **pas** un titre (le motif exige `.` puis espace).
- Si **au moins un** titre est trouvé → un chapitre par titre (même logique que le
  Markdown : texte avant le 1er titre ignoré, titre non compté dans les mots).
- Si **aucun** titre → garder le comportement P0-03 (un chapitre par page). C'est le
  plan B prévu par SPEC §10.
- `extraire_chapitres_markdown` et ce découpage partagent le même code de comptage :
  **ne pas dupliquer** la logique (extraire une fonction commune si besoin).

Cas de test (sur des **listes de lignes**, sans fichier PDF, pour rester simple) :

| Lignes | Chapitres attendus |
|---|---|
| `["Chapitre 1 Les bases", "texte a b", "Chapitre 2 Suite", "c d"]` | `Chapitre 1 Les bases` (3 mots), `Chapitre 2 Suite` (2 mots) |
| `["1. Introduction", "a b c", "2. Méthodes", "d"]` | `1. Introduction`, `2. Méthodes` |
| `["1.5 pas un titre", "texte"]` | aucun titre → repli « une page = un chapitre » |

**Fini quand** : les 2 tests sont verts, ainsi que le test 1.

## P1-02 — Ignorer les `#` dans les blocs de code Markdown

- **Fichier** : `backend/app/services/importer.py`
- **Test** : `test_importer.py::test_diese_dans_bloc_de_code_ignore`
- **Pourquoi** : un cours de Python contient des commentaires `# ...` dans ses exemples
  de code ; sans cette règle, chaque commentaire deviendrait un faux chapitre.

Règles :
- Une ligne qui commence par ` ``` ` (après espaces éventuels) **ouvre ou ferme** un
  bloc de code.
- À l'intérieur d'un bloc, une ligne `# ...` est du **contenu** (ses mots sont comptés),
  jamais un titre.

Cas de test :

````markdown
# Fonctions
texte
```python
# un commentaire
x = 1
```
## Listes
````
→ 2 chapitres : `Fonctions`, `Listes` (pas de chapitre « un commentaire »).

**Fini quand** : le test est vert, ainsi que le test 1.
